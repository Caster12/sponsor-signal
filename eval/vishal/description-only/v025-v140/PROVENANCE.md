# Provenance

All 116 labels in `labels/vishal.jsonl` were made by Vishal from the saved employer descriptions. AI was used only to format the files (the worksheet, the JSONL and this folder's layout), not to decide labels.

`seen_model_output: false` means no extension prediction was consulted while labeling. These are one labeler's labels: apart from the seven postings shared with Khushi's p011–p100 batch (listed in `README.md`), they have not been double-labeled or adjudicated, so agreement (Cohen's kappa) cannot be reported for them.

Posting texts come from the Greenhouse public job-board API, not browser captures. Each text's SHA-256 is recorded in `meta.jsonl` as `description_sha256`.
